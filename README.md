# Overseas Highway Tech Campus

A responsive, single-page website for Overseas Highway Tech Campus.

## Features

- Premium navy-and-cyan responsive layout
- Technology program discovery
- Learning pathway and enquiry sections
- Mobile navigation
- WhatsApp enquiry form (no backend or personal data storage)

## Local preview

Open `index.html` in your browser. No build tools or dependencies are needed. Google Fonts require an internet connection; fallback fonts are provided.

## Publish with GitHub Pages

1. In this repository open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then save.
4. Once GitHub finishes publishing, the expected site URL is `https://overseashighway.github.io/Tech-Campus/`.

The website uses an `oH` text-based brand mark. Replace it with the approved Overseas Highway logo asset when available.

**Note:** Program offerings, enrollment dates, fees and credentials are intentionally not claimed as confirmed. Update the site with verified information before announcing admissions.
